## 阶段 2 的第一条训练链路

优先建立项目隔离环境，并验证 CPU PyTorch 与 NumPy；先迁移原版 PyMARL QMIX。

```text
Python API / CLI
  → 配置加载与算法组合验证
  → 小型确定性离散多智能体环境
  → EpisodeRunner / BasicMAC / RNNAgent
  → EpisodeBatch / ReplayBuffer
  → QLearner / QMixer
  → 一次真实梯度更新
  → checkpoint 保存、重新加载、评估
```

该链路已在确定性 toy 中通过，真实 SMAC 3m 因外部环境缺失未验证。第 2 阶段详见 STAGE2_REPORT.md。第 1 阶段的依赖缺失记录保留为历史证据。

## 各阶段优先解决的已知问题

- 阶段 2：PATH 的 Python 是不可启动别名；应用 Python 无 torch/yaml/sacred；PyMARL 的 yaml.load、collections.Mapping、os._exit 和资源路径需兼容处理。
- 阶段 3：HMF 18 文件已逐项核实，13 个默认算法/固定组变体接通，5 个具体失败原因见 STAGE3_REPORT.md。动态 IPC/K-means、RODE 扩角色后的优化器/分组维度、q 角色组件继续保留为欠项；真实补货/SMAC 缺后端与资产。固定组通过不能替代动态执行验收。
- 阶段 4：BC/CPL 首条链路、17 个策略调用配置、6 种奖励模型与多标签初始轮次已经接入并验证短更新。hacpl/maicpl/maidpo 缺 Learner；BCQ 风格 QLearner 的三输出与所配 Controller 不兼容；ACPL 配置不完整；old_src 的参考策略、个体终止和 agent_state 缺失。NMR/PrefTransformer 等来源问题保留；完整交互/无监督/联合训练及后续信任筛选未全部通过。逐项原因见 STAGE4_REPORT.md 和矩阵，不能以默认分支通过替代。
- 阶段 5：已比较 4 份 SADMA，选王思哲算法类并保留易才润开源/闭源配置，7 个配置和 6 个额外分支完成短更新。QMIX/VDN 使用来源回放，PPO 使用一次消费的新数据；补齐旧概率/价值/策略版本及完整 checkpoint。MADDPG 空 Policy、连续电网 schema 与资产、真实 SMAC/补货/CityFlow、GPU、单环境以外执行仍未通过，详见 STAGE5_REPORT.md 和 SADMA_VERSION_SELECTION.md。
- 阶段 6：已实现新版本化 ZMQ 协议、训练/采样/推理角色、参数摘要确认、有界信用/HWM 和有限超时。SADMA Q/VDN 支持 sync/async，普通 PPO 仅 sync，async PPO 显式 use_vtrace=true；其他家族不自动接入。没有远程主机，跨机/GPU/真实环境未验；原持续 EvaluateWorker、旧共享 IPC 与多 Learner 未迁移，具体配置覆盖见 STAGE6_REPORT.md。
- 阶段 7：矩阵中所有项有实现、重复处理、范围决策或阻塞结论；保留来源和失败证据。

## 阻塞处理与状态更新

阶段 1 的完成是“盘点材料完成”，不是“原项目已跑通”。外部条件缺失不阻止准备规格和静态清单。后续阶段也可以继续独立工作，但真实环境/数据验收不降级成通过。

大规模收敛实验在本计划之外，若用户后续要求，另建实验清单和计算预算。
